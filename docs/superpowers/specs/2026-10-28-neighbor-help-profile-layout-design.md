# 邻里里「我的」页布局统一 Design

日期：2026-10-28  
状态：已落地（方案 A：头图资料 + 分组清单 + 轻渐变）  
前置：消息分段 Tab、首页暖色氛围

## 目标

整页视觉与消息/发现对齐：去 MUI 杂糅、少卡片堆叠、信息架构更清晰。

## 非目标

- 不改统计 / 帖子 API  
- 不做他人主页  
- 不改 BottomNav  
- **公告管理不进 H5**（入口与路由已撤；后续独立管理后台）

## 结构（上→下）

1. 头图内标题「我的」  
2. 头图：轻暖色渐变；头像 + 昵称 + 楼栋；可点编辑；底「帮助了 / 获得帮助」并排数字  
3. 设置：分区标题；外观三段浅色滑块；菜单行（编辑资料 / 改密码）  
4. 我的帖子：标题+数量；筛选分段；自绘列表行  
5. 退出：幽灵危险色  

弹层：`BottomSheet` + `Field` / `Button`，去掉 MUI TextField/Typography/Chip。
