# 邻里里「我的」小红书式布局 Design

日期：2026-10-28  
状态：已落地（方案 A + 上滑收顶栏）  
前置：Profile 布局统一、Waterfall/PostCard、主题图标切换

## 目标

个人页信息架构与内容流贴近小红书：头区资料 + 吸顶 Tab + 双列笔记流；设置进右上角菜单。

## 非目标

- 关注/粉丝、收藏、换封面、他人主页  
- 公告管理（仍不进 H5）

## 结构

1. **浮层顶栏**（头区可见时）：右上主题图标 + ⋯；⋯ 含编辑资料 / 改密码 / 退出  
2. **头区**：轻暖色底；大头像、昵称、楼栋；帮助了 / 获得帮助横排  
3. **上滑**：顶栏收起；Tab（全部|进行中|已完成）吸顶全宽  
4. **内容**：Waterfall + PostCard；点卡片进详情；进行中可经详情完成
