# 邻里里首页「阳光问候」布局 Design

日期：2026-10-28  
状态：已确认（对话分节 §1–§3）

## 目标

去掉首页「看板感 / 2×2 死板格」，改为：**品牌氛围问候 → 轻量贴纸入口 → 邻里动态**，更生活、更松。

## 非目标

- 不改发现页 / 发帖页结构（仅首页）
- 不改 posts/announcements API
- 不做杂志大插画首屏（方案 2）、不做一大三小剧场拼贴（方案 3）
- 不把安全提示重新铺回首屏主体

## 信息架构（自上而下）

1. **氛围问候区**（非整卡描边）
2. **公告一行摘要** → 点开 Sheet 看全部
3. **横向贴纸入口条**
4. **邻里动态**（标题 + 全部 + PostCard 无限滚动）
5. 底栏 + FAB 发帖（保留）

## §1 顶区「阳光问候」

**删除**

- 橙色「今日动态」统计大卡及其中大 CTA「发布求助…」
- sticky 顶栏上的「刷新」文案按钮（需要时可用列表旁小图标或下拉，本轮以精简为主）

**改为**

- 一整块暖色氛围背景（浅渐变 + 极淡装饰圆/光斑），**不要**厚边框卡片感
- 主视觉：display 字号「邻里里」
- 副行：按时问候（上午好 / 下午好 / 晚上好，邻居）
- 可选极小字：`今日新发 N · 累计 M`（不是大数字看板）
- 未登录：右上角小「登录」；已登录不占位

## §2 贴纸入口条

**删除** 2×2 等大彩色方格。

**改为** 横向贴纸条：

- 每项：`MenuSticker` + 短标签（menus.label）
- 可横向轻滑；允许第一个略大等轻微主次，不过度歪斜
- 点击：`navigate('/discover', { state: { type } })`（保持现逻辑）
- 热度：不用角标；标签下可选 11px「近期 N 条」，无则不显示

## §3 动态 + 公告 / 安全

| 模块 | 行为 |
|------|------|
| 邻里动态 | 紧跟入口；标题 +「全部」；现有 PostCard + 无限滚动 |
| 公告 | 去掉顶部长条跑马灯；问候下「喇叭 + 摘要」一行，点开 Sheet 列全部 notices |
| 安全提示 | 仍走现有帮助 Sheet，不占首屏 |
| 发布 | 底栏 FAB；首屏不再放大 CTA |

## 验收

- 首屏一眼是品牌氛围，不是统计看板
- 入口非 2×2 齐格，可横滑
- 动态在首屏可见区域内出现（常见手机高度）
- 明暗主题可读；`npm run lint` + `npm run build` 通过
