# 邻里里帖子详情「小红书式」布局 Design

日期：2026-10-28  
状态：已落地（方案 1：就地改 PostDetail）  
前置：沉浸封面（`2026-10-28-neighbor-help-post-detail-cover-design.md`）、卡片瀑布流、API DTO cover 宽高

## 目标

详情页信息架构与互动层级贴近小红书笔记：大图按比例、封面下作者行、互动沉底栏；保留邻里业务（响应 / 私信 / 采纳 / 联系可见性）。

## 非目标

- 收藏、分享、关注
- 评论楼中楼、双列详情
- 改 API / DTO（沿用现有 `cover`、`author`、`stats`、`viewer`）

## 决策摘要

| 项 | 选择 |
|----|------|
| 范围 | 封面真实比例 + 作者/正文结构 + 融合底栏（用户选 C + 底栏 B） |
| 实现 | 就地改 `PostDetail.jsx`，不拆新组件文件（本轮） |
| 封面高度 | 真实 h/w，夹约 0.75～1.6，且不超过视口 ~70% |
| 作者管理 | 底栏右侧 ⋯：编辑 / 标记完成 / 删除（对齐小红书「管理进菜单」） |
| 访客主操作 | 底栏：响应 / 私信 / 登录（按类型与状态） |

## 布局结构（上 → 下）

1. **沉浸封面**  
   - 全宽横滑 + 指示点；顶栏叠层：返回 / 刷新 / 举报（非作者）  
   - 高度：优先 `post.cover` 宽高，否则预加载首图；`clamp(h/w, 0.75, 1.6)`，再 `min(算出高度, 0.7 * viewportHeight)`  
   - 类型 pill + 相对时间叠封面；已结束遮罩  
   - 无图：类型色块 + `MenuSticker`，高度约 `min(屏宽×0.85, 0.7vh)`

2. **作者行**  
   - 头像（或首字）+ 昵称 + 楼栋/单元弱文案  
   - 不放关注；不放点赞

3. **正文**  
   - 标题 → 正文  
   - 轻信息块：地点 / 联系 / 响应后可见提示（现有隐私规则）  
   - 已采纳 helpers chip（有则显示）  
   - **移除**正文区内嵌赞、并排「编辑/响应/私信」主操作条

4. **评论**  
   - 标题「回复 · N」；列表与无限滚动、删评/举报 Sheet 不变

5. **固定底栏**  
   - 左：评论输入（「说点什么…」，行为与现底栏输入一致）  
   - 中：赞（心形 + 数；读写 `viewer.liked` / `stats.likeCount`，fallback 旧字段）  
   - 右：  
     - 未登录 →「登录」  
     - 访客 + 可响应类型 → 未响应主按钮文案（我要帮忙/…）；已响应 →「私信」；关帖禁用或隐藏主按钮  
     - 访客 + 非响应类型 →「私信 TA」  
     - 作者 → **⋯** 菜单：编辑（open）、标记完成（open）、删除（确认 Sheet）

## 交互保留

- 采纳候选人 Sheet、关帖、删帖、举报帖/评、大图 viewer、联系复制  
- `location.state.openAdopt` 自动打开采纳 Sheet

## 实现面

- 主文件：`neighbor-help/frontend/src/pages/PostDetail.jsx`  
- 复用：`utils/image.js`（`coverAspectRatio` / `coverKey`）、`utils/imageAspect.js`（`clampAspect`）、`utils/typeTheme.js`  
- 可在同文件内抽小函数/子组件；本轮不强制新建 `DetailCover.jsx` 等文件

## 验收

- [ ] 竖图封面明显高于旧固定 240，横图不会无限拉高（受 70vh 与比例夹限）  
- [ ] 视觉顺序：图 → 作者 → 文 → 评；赞与主操作在底栏  
- [ ] 访客可赞、可响应/私信；作者经 ⋯ 编辑/完成/删除  
- [ ] 联系方式可见性与 Sheet 逻辑无回归  
- [ ] `npm run lint` / `npm run build`（frontend）通过

## 与旧详情封面 spec 关系

本设计**覆盖并延伸**沉浸封面 spec 的信息架构；封面叠层顶栏规则继续有效，高度算法以本文件为准。
