# 邻里里 PostCard 杂志条目 Design

日期：2026-10-28  
状态：已确认（§1–§3）

## 目标

帖子列表卡改为**杂志条目**：去厚框阴影，有图通栏上图下文，元信息一行轻量展示。

## 非目标

- 不改列表 API / 字段
- 不做左图右文、不做类型色竖条方案
- 不新建第二套卡片组件

## §1 容器

- 无 boxShadow、无实线边框厚盒
- 页面底上的条目；间距靠留白（约 16–20px），不以硬分隔线为主
- 整块可点；轻 scale；尊重 reduced-motion

## §2 图文

- 有图：上图（全宽、圆角 14–16、高 ~160–180）→ 标题 → 摘要 2 行
- 无图：直接标题 + 摘要，无占位块
- 去掉标题上方 cream Sticker

## §3 元信息

- 一行：`类型 · 地点 · 时间 · N 评`（缺省省略）
- 类型可用 12px MenuIcon + label
- 仅「已结束」显示；不显示「进行中」pill
