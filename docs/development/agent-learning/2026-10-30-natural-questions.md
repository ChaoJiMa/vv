# 报告助手自然问法与本地追问

- 日期：2026-10-30
- 范围：`agent-learning/` 本地问题识别、字段查询与会话上下文。
- 状态：已完成本地实现与离线验证；真实业务正文的完整问答未实连验证。

## 需求与原因

用户反馈多数问题只返回“本轮问题保留在本地……”的固定提示。
核实原因是模型出口仅接受三个主题的完整白名单句式，而本地兜底只匹配完整字段名或路径；
口语、模块关键词、字段别名和选定字段后的追问均容易落空。多版本目录中字段名称与模块名称
分开登记，部分申请统计另有机构数、分项、档位，不能仅按模块取前六项充当总次数。

## 方案与改动

- 保持原模型出口白名单，另设只在本地工作的问法识别层；不发送原问题或报告值。
- 结合当前主题启用字段，识别关键词、常见别名、统计窗口和规则解释操作。
- 支持选择字段后的含义和窗口追问，多个候选明确选择，无匹配时给出当前报告可查的模块。
- 收紧申请总次数的候选口径，避免混入机构数或细分类别；缺失、空值与零保持原语义。
- 同步使用说明、接口文档的本地工具说明和文档索引。

实际新增 `report_questions.py`，使用当前主题启用字段识别口语、概念别名、
模块与滚动周期；结果通过 `LocalQuery` 交给 `report_session.py` 组装。
模型出口仍对完整问题独立批准，本地识别结果不传回模型，也不改变原出口语法。
选定字段的跨周期候选限定同模块和同指标；未知新问题清空旧指代，历史保存失败不提交内存选择。

`report_tools.py` 的总次数映射排除机构数、夜间和类别分项，兼容“非银”模块名、
小写周期和 `month12` 编码。候选可显示从路径编码识别的周期，重复标签附模块和路径以便区分。
原有缺失、null、空字符串、零值和数组语义保持不变，档位不转换成精确次数。
新增20项有意义的回归用例，同步 README、Java接口文档中的 Python 本地工具说明及文档索引。

## 使用与限制

这是本地字段和登记规则的查询扩展，不实现任意语义推理、风险评级或审批预测。
真实业务正文的完整问答尚未在本次实连验证。

退出原进程后重新运行 `agent-learning/main.py`。可以问“我有没有逾期记录”
“最近一周非银申请了几次”；有多个候选时用 `/pick 序号` 或“选择第1项”。
选定后可继续问“这个是什么意思”“它的值是多少”“那近1个月呢”。
“帮我分析这份报告”列出可查模块供逐项查询；超出识别范围的问法给出本报告的检索示例。
候选较多时需要补充字段、模块或周期，自然月与多周期比较目前要求明确单个滚动周期。
