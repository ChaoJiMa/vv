# 报告助手接入多种报告版本

- 日期：2026-10-30。
- 范围：`agent-learning/` 字段资料导入、本地报告工具、报告选择与相关文档。
- 状态：多版本接入与离线验证已完成；各版本真实服务正文和完整问答未逐一实连验证。

## 需求与原因

用户要求对接多种报告，现有导入器只取个人严谨版 `theme=3`，本地工具据此拒绝其他版本。
参考工作区已获取的 `origin/report-server`（`5ca0dbc7ae51b553e7ac96b95e241be1ee3b3a0f`）
提供 12 个主题的权威字段表及严谨版、其他主题补充资料，共 18170 行。

## 方案与改动

1. 按报告 `template.theme` 精确选择独立字段目录，按当前模板的 `moduleId` 继续过滤。
   12 个主题分别保留自己的字段、展示规则和枚举，不按外观复用关系套用其他主题规则。
2. 导入器固定同一 Git 提交，读取全部主题资料；严谨版后端补充仅用于严谨版，
   其他主题只按各自的模块与路径匹配补充资料，未登记的口径不补造。
3. 支持已有资料中的数组、数字键、动态对象键路径；含多个候选路径的字段分别展示原值，
   不解释或执行表达式；固定文案保留规则，不当作报告值读取。
4. 选择成功显示识别的报告版本，未知主题与字段资料异常分别提示；保留 Java 登录、
   用户列表复核、正文 ID 一致性校验、模型出口限制与本地加密历史。

| 文件 | 实际改动 |
|---|---|
| `agent-learning/scripts/import_report_fields.py` | 分离纯资料合并与 Git 读取，导入全部主题并保留来源；补充口径冲突时不猜选；统一 UTF-8/LF 输出 |
| `agent-learning/data/report_fields.json` | 更新为 `schema_version=2` 的 12 主题目录，共 18170 条定义，包含 134 条固定文案 |
| `agent-learning/report_tools.py` | 精确匹配主题，兼容显式传入的单主题目录，新增动态键与候选路径读取、路径语法校验及本地版本元数据 |
| `agent-learning/main.py` | 显示识别出的版本，分别处理未知版本和资料异常，移除仅支持严谨版的提示 |
| `agent-learning/tests/test_themes.py` | 新增 14 项测试，覆盖版本/模块/会话/模型出口隔离、路径语义和导入来源 |
| README、接口说明、文档索引和基线记录 | 同步版本清单、目录格式、操作说明、实际验证结果与历史快照后续入口 |

本轮移除了 `main.py`、`report_tools.py` 原有的 UTF-8 BOM，并统一任务代码的换行；
不修改本机 `.env`、其他子项目或 Git 暂存区。

## 使用与限制

沿用现有启动、登录和 `/orders` 流程，无需新增配置。未知主题继续拒绝，不回退到严谨版。
仅解释已登记规则和原始字段，不实现网页全部展示计算或推断审批结果。真实服务各版本正文
与完整问答尚未逐一实连验证。版本清单、启动及重启方式见
[运行说明](../../../agent-learning/README.md)，协议和本地目录结构见
[接口说明](../../interfaces/agent-learning/java-business-api.md)。
