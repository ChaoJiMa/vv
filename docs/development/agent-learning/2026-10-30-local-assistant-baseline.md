## 当前目标与实现

用户在终端查询当前绑定报告的字段值及已登记规则。Python 本地读取报告快照，
外部模型可选启用，只用于批准意图的工具请求及受限表达模板，最终答案由本地组装。

| 模块 | 现有职责 |
|---|---|
| `report_tools.py` | 校验报告主题与模块，登记字段白名单，保留缺失/null/空字符串/0 的不同语义 |
| `report_privacy.py` | 完整问句白名单、不可变查询枚举、模型消息构造、工具参数及模板精确校验 |
| `report_session.py` | 分离完整本地历史和最近 8 轮枚举历史；模型调用结束后本地取值与组装答案 |
| `local_history.py` | 当前 Windows 用户 DPAPI 加密后写入 SQLite，按报告绑定筛选历史 |
| `scripts/import_report_fields.py` | 从本地 Git 提交读取通用字段资料，记录来源，不自动拉取远端 |

本地支持 `/find` 检索、`/pick` 选字段和 `/history` 回看。演示数据必须明确标记为虚构。
字段资料当前支持个人严谨版 `theme=3`；不包含完整评分展示计算、任意报告分析或审批预测。

以上为本记录整理时的实现快照。后续已扩展到 12 种主题，当前能力与验证见
[多版本接入记录](2026-10-30-multiple-report-themes.md)；评分计算和审批预测仍不在支持范围。
