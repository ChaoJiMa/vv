# 两个 Python 入口直接运行

- 日期为 2026-11-18。
- 范围为 D7 练习入口、报告助手入口及运行说明。
- 状态为已实现并通过本地验证。

## 需求与原因

用户希望打开仓库根目录后直接运行两个 Python 文件。此前直接运行练习入口时，模块查找从 D7 文件所在目录开始，
无法导入 D6。报告助手在根目录用默认 Anaconda Python 启动时，缺少 `python-dotenv`。项目内虚拟环境可以启动报告助手。

## 方案与改动

- D7 入口直接执行时，根据文件位置把练习项目根目录加入模块查找范围，复用现有 D6 汇总函数。
- 报告助手直接执行时在导入第三方库前检查启动依赖。依赖缺失时，使用同目录现有的 `.venv` 解释器启动，
  继承标准输入输出并返回子进程退出码。已有依赖的解释器仍可直接运行。
- 同步两个项目的 README。Java 接口和任务指令契约沿用原有定义。
