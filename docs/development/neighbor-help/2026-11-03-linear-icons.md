# 邻里互助图标改为简洁线性风格

- 日期：2026-11-03。
- 范围：neighbor-help 前端图标、分类入口、空状态与相关装饰。
- 状态：本地实现与验证完成，未部署。

> 后续视觉选择：用户在对话内比较方案后，明确选择糖果色与胶质角色，并要求保持原项目布局。分类入口的最新实现以 [糖果胶质视觉调整](2026-11-03-gummy-theme.md) 为准；本文保留此前线性方案的实际改动与验证记录，关键导航和提示线标仍沿用。

## 需求与原因

用户不喜欢当前插图和 icon，并明确选择“简洁线性：统一描边，低彩度，偏工具类产品”。原分类采用拟人太阳、纸箱、钥匙与购物袋贴纸，空状态为大幅彩色 SVG，与用户希望的简洁方向不符。

## 方案与改动

- 基于现有 SVG 组件统一 24 网格、1.8 圆端点描边和 currentColor，不引入图标依赖或位图；装饰图标不进入焦点顺序。
- 新增 `CategoryIcon`，分类改为援手、纸箱、钥匙与双人，移除笑脸、固定多色底和装饰；`MenuSticker` 保留兼容外壳，避免影响既有调用。
- 首页分类、发现筛选和发布分类使用中性色容器；选中仅用主题主色细边及浅背景表达。
- 空状态采用 64px 单色文档、搜索、消息、铃铛与缺失文件符号，保留状态说明，默认不渲染 emoji 或空图占位。
- 发现用指南针、搜索独立放大镜，浅色主题保留太阳，求助与新手提示分别用援手/信息图标；新增四格与公告线稿。导航以颜色表达选中，点赞保留实际填充状态。
- 登录标记和发布按钮去掉渐变装饰；无图详情改为 144px 加安全区的轻量分类头，有图片的详情尺寸与画廊行为不变。安全提示和感谢操作移除 emoji，统一信息/心形线稿。
- 保留业务操作、路由、查询、草稿和热区约定，同步检查明暗主题及窄屏。

## 使用与限制

本轮为图标视觉修改，不调整后端接口、配置或交互流程。保留其它任务既有改动，不包含提交或部署。纯 SVG/样式修改没有新增镜像测试；回归检查沿用现有测试，手机原生渲染仍需真机验收。

工具提示包括现有 Node 代理实验性提示、Vite 插件 esbuild/oxc 弃用和 Browserslist 数据过期，本轮没有升级依赖或修改代理配置。实际浏览器预览不连接生产服务或真实账号。
