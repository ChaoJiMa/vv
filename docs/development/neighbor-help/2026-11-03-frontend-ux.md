# 邻里互助前端体验逐项优化

- 日期：2026-11-03。
- 范围：neighbor-help 前端浏览、发布、消息与页面可读性。
- 状态：本地开发与验证完成，未部署。

## 需求与原因

用户确认按前端审查建议逐步修复：发现页返回后丢失分类、关键词及浏览位置；发帖离开保护不完整；分页与聊天失败恢复不足；无图卡片、字号及热区需要改善；登录表单受品牌动效延迟；聊天自动滚动可能打断阅读。

## 方案与改动

1. `Discover` 的分类与已提交搜索词改存 URL；首页分类入口同步使用查询串。搜索提交后收起、可再次展开或清除；切换条件显示更新中，禁止用上一组占位数据继续自动分页。
2. 新增 `useDiscoverScroll`，按账号、筛选 URL 与历史条目保存位置和页数。真实数据及列宽就绪后还原；缓存丢失则顺序补页。滚动/点击前记录坐标，避免卸载时文档变短导致坐标被截断；刷新后保留其它有效历史位置。补页失败保留恢复目标，人工重试成功后继续恢复；历史返回取消错峰入场，避免原位置的卡片短暂不可见。
3. `App` 使用 React Router 数据路由支持 `useBlocker`，原路径、懒加载及鉴权不变；新增统一 `RouteError` 避免框架默认异常页面。`CreatePost` 按用户/新建或编辑目标重建表单，使用 `usePostDraft` 自动保存 24 小时文字草稿，统一底栏、取消、浏览器返回保护及原生刷新提醒。提交成功/明确放弃清理，存储失败不冒充草稿已保存，上传图片 key 不入草稿。
4. `PostFeed` 区分下一页失败与后台刷新失败，保留已有内容、暂停自动哨兵并提供手动重试。`Home/Discover/Profile` 同步传递准确错误阶段。`Chat` 仅将后端 `3002` 判为会话失效，其余错误保留消息和输入并允许重试。
5. 新增 `useChatScroll`，首次进入、主动发送或接近底部时跟随新消息；阅读历史时提示新消息；加载更早消息按可见气泡补偿，兼顾请求期间继续滚动。会话和账号切换重建输入/滚动状态，消息按 id 去重。
6. 无图 `PostCard` 改为文字摘要卡，展示公开地点；有图保留封面及懒加载。主内容链接与点赞按钮并列，保留修饰键打开新标签页和键盘行为。标题 15.5px、底栏 12px、点赞至少 44×44px，≤360px 隐藏作者头像以保留昵称与时间。`Waterfall/imageAspect` 同步估算文字卡高度。
7. 中文页面改 `lang=zh-CN`，允许浏览器缩放；登录表单及辅助入口首帧可见，品牌单独等待字体与播放动效。

本轮不调整后端 HTTP 协议；更新子项目与前端 README，并新增 [前端导航约定](../../interfaces/neighbor-help/frontend-navigation.md)。

## 使用与限制

草稿仅在当前标签页保存文字和“图片有改动”的提示，最长 24 小时；图片需要重选，编辑原图仍从服务器读取。浏览位置最多 40 个条目、每条最多补回 50 页；内容删除或列表变短时恢复到最近可达位置。浏览器是否展示原生刷新/关闭提示取决于内核及用户交互状态。

已完成本地桌面浏览器移动视口检查；尚未做 iOS/Android/微信真机键盘及原生离开提示验收。保留其他任务现有改动；未提交、推送或部署。

已经发送到服务器的单次图片上传不保证撤回；本轮阻止离开后启动后续上传并忽略迟到结果，未引用图片仍由现有后端清理流程处理。
