## 需求与原因

用户希望获得一套完整的学习流程和课程。现有 `docs/roadmap.md` 已列出 D1–D56 的主题和粗粒度验收，但缺少贯穿 56 课的详细任务、正常及边界检查和统一学习流程。用户有前端经验，主要为 Python / Agent 应用开发转岗求职，每天约 2–4 小时且会被工作打断；已明确偏好综合题，并要求题目、代码和作答位于同一练习文件。

## 方案与改动

- 新增完整课程文档：8 阶段、D1–D56 每课的知识目标、同一任务助手项目增量、正常/边界验收和阶段面试表达；编号是参考主题，可据实际掌握合并或补练。
- 新增可重复执行的学习流程：当前计划、短讲解、独立实现、检查、反馈、复测和阶段验收；将已学知识与未验证能力区分。
- 当前练习仍以 `exercises/day01/task_info.py` 为入口，保留用户已写的输入处理代码和所有既有作答。课程蓝图可提前完整查看，具体同文件练习在学习到对应单元时按进度展开，避免一次生成大量空骨架。
- 同步项目 README、协作规则、路线和根文档索引。无运行时 API、依赖或密钥变化。
