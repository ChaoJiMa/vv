# 邻里互助前端导航约定

- 验证日期：2026-11-03。
- 调用方：首页分类入口、发现页筛选与搜索、浏览器历史、分享链接。
- 范围：前端页面地址；本次未新增或修改后端业务 HTTP 接口。

## 发现页

页面地址：`/discover`，公开可访问，不要求登录。查询参数位于 URL 查询串：

首页和发现页在游客状态下不展示顶部右上角登录按钮；发现页保留搜索，消息页保留原鉴权保护。需要登录的发布等操作继续走既有登录引导与回跳，不增加新的入口或路由。

| 参数 | 必填 | 含义 |
|---|---|---|
| `type` | 否 | 当前菜单的分类值，如 `help`、`idle`、`lost`、`group`；省略表示全部 |
| `keyword` | 否 | 已提交的标题/内容搜索词，前端请求时去除首尾空白；省略表示不搜索 |

示例：`/discover?type=idle&keyword=台灯`。切换分类保留已提交关键词；清除搜索保留分类；不删除 URL 上其它查询参数。筛选提交创建新的历史条目，返回/前进按目标 URL 重新选择条件。

页面仍调用现有 `POST /api/posts/list`，参数仍为 JSON `{ type, page, keyword }`，成功条件仍为响应 `code === 200`，消费 `data.list/page/hasMore/total`。当前用户的鉴权头与查询缓存隔离沿用 `api.js` 和会话上下文，不改变后端公开/登录可见规则。

## 浏览位置与发布保护

注册使用公开页面 `/login?view=register`，邀请码与账号、密码、确认密码在同一页；该查询参数只选择表单视图，不携带个人资料或密码。从登录入口进入时保留 `location.state.from`，返回恢复入口，成功后回到原操作；直接访问深链的返回按钮落到 `/login`。原 `/login` 与微信 `code` 回调处理保留，未新增短信登录。注册字段及能力查询见 [注册接口约定](registration.md)。

注册布局挂载时临时让唯一浏览器 `theme-color` 与顶部安全垫层使用头图起色，底部垫层接当前主题的表单底色：浅色白底，深色中性深底。输入、文字及主操作同时跟随主题；切主题时仍从同一CSS色源读取，最后一个注册布局卸载后恢复当前主题。此状态不写入主题偏好；直接刷新注册深链先由head脚本提示相同颜色，实际布局未接管时普通主题同步会清理标记，不改变URL、鉴权或注册接口。

发现页以账号、历史条目和查询串区分位置，仅在当前标签页保存滚动坐标与已加载页数，不保存帖子列表。真实数据和瀑布流布局就绪后恢复；缓存丢失时按既有接口顺序补页。补页失败停止自动恢复请求，由用户手动重试；主动滚轮、触摸滚动或阅读方向键中止自动定位，后续数据完成时不再把用户拉回旧位置。最多补回 50 页，最多保存最近 40 个位置。

发布路由仍为受保护的 `/create` 和 `/edit/:id`。切换为数据路由仅用于统一拦截站内离开，登录回跳与既有路径保持原有行为。新建、编辑和不同账号的文字草稿隔离；成功提交或明确放弃清理，图片 key 不进入草稿。

底栏仅在目标导航提交后回顶，跳转被草稿保护拦截时保留编辑位置；浏览器返回不重放回顶标记。编辑取消优先返回原来源，直接深链进入编辑时回退原帖详情。刷新/历史返回优先保留草稿中最后选择的分类，明确的新发布入口可指定新的分类。

## 开发素材预览

`/dev/characters` 仅在 `import.meta.env.DEV` 为真时注册，本地开发可直接进入，无需登录，不增加正式底栏入口。当前调试会话的同 Wi-Fi 手机地址为 [角色组合预览](http://192.168.10.219:5173/dev/characters)；电脑IP变化后需替换为实际局域网地址。生产构建不注册或打包该调试页，业务页面使用的角色图集仍保留。

预览路由与产品的会话布局同级，不挂载`AuthProvider`，已有本地登录缓存时也不会发起账号恢复请求。直接进入或经浏览器历史返回业务路由时，仍由原Provider恢复账号；业务路由内部和其错误恢复共用稳定会话布局，原登录拦截与来源跳转不变。

页面使用真实运行素材 `gummy-neighbors-personas.webp`（1448×1086、4列×3行、499,988字节），可将12种形象 / 表情与粉色、奶黄、淡紫、蓝色独立搭配成48种组合，也可自选六位 RGB 颜色。选择颜色保留形象，切换形象保留颜色；组件的 `expression` 为整数0–11，`color` 为预设名或 `#RRGGBB`，原 `type` / `variant` 行选择继续兼容。SVG `feColorMatrix` 换色保留黑白、灰阶和 alpha。旧 simple / cheerful / mellow 素材仅为草稿，不参与运行显示。页面自身不请求API、不创建账号或使用业务模拟数据；组件参数与有效示例见 [前端 README](../../../neighbor-help/frontend/README.md)。

## 验证边界

使用 Vitest/jsdom 验证 URL、历史、缓存补页与草稿保护。早期本地浏览器曾使用独立内存模拟 API 验证搜索、详情返回，以及底栏 / 浏览器返回的草稿恢复；该阶段未连接生产 Worker、D1 或 R2，属于历史验证方式。

本轮公开页面查看使用项目现有 Worker 的真实公开响应，不再以内存模拟 API 作为预览数据源。`/dev/characters` 则只组合真实图片素材，页面自身不请求业务接口，两种查看用途应分别理解。手机原生键盘与离开提醒仍需真机验收。
