# Python 报告助手的项目约束

仅在修改 `agent-learning/` 时读取本文件。运行和最新接口细节以该目录 README、代码及
`docs/interfaces/agent-learning/java-business-api.md` 为准。

## 已确定的职责

- Python 负责终端交互、Java 接口调用、本地字段查询和加密历史。
- Java 负责验证码校验、业务用户识别、token 签发及报告数据访问授权。
- 继续调用 Java 已有接口；用户未要求迁移时，不新建独立账号库或自行签发业务 token。
- 业务客户端与模型客户端分别创建，模型不能指定用户、订单或任意字段路径。

## 修改时保持的关键行为

- `test` 登录模式仅允许固定测试网关，调用 `sendGeneral` 后再调用 H5 登录；`sms` 使用已有验证码。
- 自动获取的 token 留在内存，不回显、不写回 `.env`，不放入问答历史或模型消息。
- 报告先从当前用户列表选择，正文读取前复核，返回 `report_id` 必须与选择一致。
  客户端检查不能代替 Java 正文接口的授权。
- 用户于2026-10-31进一步明确：报告业务内容只有姓名、证件、手机号、地址不给模型，其他内容均可按需用于分析。analysis策略支持文字、布尔、数组、对象、案件明细及字段说明，读取出口先在本地递归过滤四类个人信息；普通报告文字和业务编号不再一律作为私有值。运行凭据及完整历史不外发，工具仍绑定当前报告并使用引用，不接受模型传入原始路径。通用问答分支不附带报告工具、事实或旧问题。旧template协议继续保持枚举和固定回执边界，不能与新策略混用消息。
- 工具权限绑定当前报告，用不透明引用取值；程序校验参数、调用预算、来源引用与数字。已知私有值及常见格式检查失败时整轮留在本地；自由文本检查不保证完全匿名化。模型异常回退本地，不发送异常正文或原始问题重试。
- 小贝客服使用本地固定知识或模型选择的封闭service主题；完整短句可本地答复，复合问题不截断。联系方式以用户提供的业务资料为源，不能扩写未核实的政策、来源背书或审批承诺；身份不可外发不等于报告没有该字段，当前报告不代表名下报告总数。客服不执行申诉、退款、工单或接人工，保存成功后清空旧报告指代。
- 缺失、null、空字符串和 0 保持不同含义；模板与字段资料不匹配时拒绝套用规则。
- 完整历史先经当前 Windows 用户的 DPAPI 加密再写 SQLite，不生成明文备用文件。

## 验证入口

在 `agent-learning/` 内使用已有虚拟环境：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

这些测试使用虚构凭据、内存 HTTP 和临时历史库，不读取 `.env`，不访问网络。
只改注释时可比较移除文档字符串后的 Python AST；该比较只能证明可执行语法结构一致，
仍应检查注释是否准确，不能据此声称运行时元数据或接口实连已重新验证。

实连只在当前任务需要且已有授权时执行，记录 HTTP 状态、业务码和有无报告即可，
不输出凭据或个人报告。报告列表为空不能证明正文读取及完整问答成功。
