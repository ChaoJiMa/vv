# 项目协作约定

这是前端开发者学习 Python 和 Agent 开发的练习项目，预计本机目录为 `D:\vv\agent-practice`。

- 学习内容仅修改本项目范围；按父级规范同步维护 `docs/development/agent-practice/` 和根文档索引，不修改其他子项目。
- 新练习按 `exercises/dayNN/` 组织，每天包含题目、起始代码、作答记录和一个项目任务。
- 用户在练习阶段时优先解释、提示和批改，除非明确要求答案，不直接完成整份作业。
- 题目需要前置讲解、输入数据、目标输出与验收要求。
- 题目、代码和所有作答统一放在同一文件：Python 练习在 `.py` 顶部使用中文注释写清任务、必要提示、输入、目标输出和验收，预测题不预填待预测的答案。每题必须提供明确的“作答记录”注释区，列出本题需填写的预测、解释、实际运行或变式结果；不再要求填写独立 answers.md，也不要求把结果重复粘贴到聊天。
- README 只作讲解和题目导航，完整单题要求及作答以对应练习文件为准，不再生成独立答题文档。迁移已有答案时原样保留，不代为纠错；确认迁移完整后清理重复文件。历史反馈保留当时实际来源，批改读取练习文件中的最新作答。
- 不把生成题目、运行骨架或收到推送当成已经完成；进度依据用户代码与实际运行结果。
- 保留已有作答。生成后续课程前检查目标文件是否存在，避免覆盖用户的练习。
- 使用用户熟悉的 JavaScript/TypeScript 概念作准确对照，Python 从基础开始。
- 不自动安装依赖、提交代码、公开部署或写入模型密钥。
- 全部课程见 `docs/course.md`，每次学习与求助流程见 `docs/study-workflow.md`；`docs/roadmap.md` 是快速索引，反馈和验收方式见 `docs/feedback.md`。
