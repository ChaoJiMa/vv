# 邻里互助前端

React 19 + Vite，使用 React Router 数据路由、TanStack Query 和奶白 / 中性深色主题。主操作采用高对比黑白色，分类入口使用糖果色与原创胶质角色。生产部署到 Cloudflare Pages，后端为独立 Worker。

## 本地开发与检查

使用 Node.js 22.13 或更高版本。在本目录执行：

```powershell
npm ci
npm run dev
npm test
npm run lint
npm run build
```

本地开发默认监听 `5173`；`/api` 和 `/auth` 代理到 `127.0.0.1:8787`，需另行在 `../worker` 启动 `npx wrangler dev`。`VITE_API_URL` 留空时走同源代理，也可配置独立 API 地址；微信登录需要 `VITE_WX_APPID`。配置与部署步骤见 [项目 README](../README.md)。

手机调试时，让手机连接电脑所在路由器的 Wi-Fi，浏览器访问 `http://电脑的局域网IPv4:5173/`，例如 `http://192.168.1.100:5173/`。电脑可以使用网线连接同一路由器；配置中的 `server.host: true` 允许局域网访问。手机不能使用电脑上的 `127.0.0.1` / `localhost` 地址，也不能使用 VMware 等虚拟网卡或 `169.254.*` 自分配地址。API 和热更新通过同一前端地址访问，无需在手机上设置后端回环地址；防火墙需允许该前端进程的 TCP 5173 入站。访客 Wi-Fi、客户端隔离或不同网段可能阻止设备互访。

## 页面使用

- 发现页的分类和已提交搜索保存在地址栏，例如 `/discover?type=idle&keyword=台灯`；可刷新、分享或从详情返回。搜索提交后收起输入框，点击搜索图标可再次修改，清除搜索保留当前分类。展开搜索时输入框可在窄屏收缩，长关键词在框内滚动，清除及提交按钮保留占位。
- 发现页按账号及历史条目恢复滚动位置；刷新导致查询缓存丢失时，先补回已经浏览的页数再还原位置。恢复期间主动滚动会停止自动定位，保留当前阅读位置。仅在当前标签页保留最近 40 个位置，每个位置最多补回 50 页；数据被删除或列表变短时，浏览器会落在最近可达位置。
- 新建与编辑分别自动保存文字草稿。底栏切换、取消及浏览器返回都会提示继续编辑、保留文字草稿离开或放弃修改；刷新和关闭使用浏览器原生离开提示。
- 文字草稿按账号及帖子隔离，在当前标签页保留 24 小时。重新进入会自动恢复并提示；发布成功或明确放弃会清除。图片改动不保存在草稿中，恢复时需要重新选择；编辑原图从服务器重新读取。存储不可用时会提示复制文字，不能确认保存成功就不会按“保留草稿”离开。
- 保存期间暂时锁定表单和分类，避免提交后新输入被跳转丢失。编辑取消返回原来源，直接进入编辑链接时回到帖子详情。上传中的图片同样计入最多 6 张的限制；离开编辑器后停止后续上传队列，已经发出的单次上传可能继续完成。
- 编辑页收到更新的原帖时，仅同步尚未编辑且未恢复草稿的表单；已经输入的内容和恢复草稿继续保留。“我的帖子”切换状态时会标明正在更新，收到新结果后才显示对应空状态。
- 帖子列表、私信、通知和详情评论分页失败保留现有内容，重试失败页；临时刷新失败可就地重试。帖子详情仅在明确不存在或无权访问时撤下缓存内容，聊天仅在明确的会话错误时显示失效。
- 详情中的二级回复首次加载失败也可重试；发送评论期间继续输入不会被迟到的成功响应清空。切换帖子或账号会隔离评论输入、回复目标等页面状态；详情后台刷新保留已经加载的评论页。
- 聊天阅读历史时有新消息提示；首次进入、接近底部或主动发送时跟随最新消息，加载历史消息时保持当前阅读位置。
- 同一主题内，登录及业务页默认共用粉紫 / 奶杏四角柔光背景，中央保持干净；浅色基础色为 `#f9f9f9`，暗色使用低饱和微光。整页只设一层固定画布，文档流区域透明透出；吸顶与底部固定栏按同一画布的顶 / 底位置取色，避免每段重复渐变。色源仅在 `index.html` 定义，首帧恢复主题；单个 `theme-color` 默认同步基础色，注册页临时对齐暖黄头图，离开即恢复。注册表单浅色白底、深色中性深底，底部安全区与面板同步。糖果卡片、角色、消息气泡和悬浮导航保留局部材质；iOS 浏览器界面实际着色由浏览器决定，需真机确认。
- 页面支持明暗主题和浏览器缩放；分类入口、发布分类和无图详情使用原创胶质角色，导航使用线性图标与真实实心选中态，搜索、提示与错误状态保留清晰线标。角色在原占位内放大绘制，发布分类在原两列卡的右上留白展示大角色；糖果底配合细高光、轻叠层和柔影。角色动效只响应操作，并遵循减少动态效果偏好。首页原有横排分类、双列瀑布流和固定底部导航功能保留；邻里动态帖子统一使用浅 / 深主题下的中性实色卡面，仅左上角分类标签按分类配色。无图卡继续为大角色预留分类头区，窄列和长分类会自然换行、卡片随之增高；有图卡保留原封面。发现与个人页帖子继续使用白色 / 深色底及轻微分类光泽。各页保留标题、摘要和公开地点，点赞与进入详情是独立操作。
- 底栏采用内容区宽度 66.7%（至少 240px）、高 72px 的半透明悬浮胶囊，底距取 32px 与系统安全区的较大值，页面按实际浮动范围预留底部空间。原五项路由和等权入口保留，选中图标显示真实实心轮廓；保留未读角标、鉴权、草稿拦截和发布分类流程。
- 首页、发现与聊天列表顶部标题使用同款 KaiXinTi 品牌字形；发现 / 聊天保留34px字号，常规字重、正体及与首页相同的字距，文字与粉橙卷线 / 小星装饰间保留8px正间距。标题仅等待文字字体就绪，卷线与同行按钮立即可用；字体失败或超时仍使用稳定系统回退。首页“邻里里”旁复用同一 `TitleDoodle`，字标原字体及布局保留。消息页继续区分私信与通知；搜索只筛选当前已加载的昵称、来源帖子和消息文字，并明确提示范围。筛选期间停止自动翻页，可点击“加载更多后继续查找”，清空后回到正常列表。顶部刷新为44px透明无边框图标按钮，等待仅旋转图标且不可重复点击；此入口不套用通用灰色禁用底。聊天头像、来源链接、气泡和固定输入条保持糖果材质与原发送行为。
- 首页、发现与消息顶部共用20px加安全区的起点及44px标题 / 操作行，标题与搜索、刷新按钮垂直居中。首页字标与下方问候文案间距为16px，统计 / 公告随文档流排列。未登录时首页和发现页右上角不显示登录按钮，需要鉴权的操作保留原登录引导。
- 登录入口页使用淡化倾斜糖果拼贴与连续全屏背景、中轴 82px 三角色小图标；“账号密码登录”胶囊靠近页底，与下方“注册账号 / 先逛逛”行相距16px，注册在前、两个文字入口样式一致。账号 / 公开资料说明独立放在文档流页底，使用10px辅助字，保留20px加安全区的底距；短屏自然滚动，不用fixed覆盖操作。保留原“邻里里”KaiXinTi、40px字号、4px字距、品牌位置和两组 SplitText 参数。拼贴透明遮罩及背景不变；忘记密码和已配置时的微信入口仍在账号弹层，入口不等待装饰入场。
- “注册账号”进入 `/login?view=register` 单页引导：顶部糖果角色欢迎区，下方同页填写账号、密码、确认密码和选填邀请码，不增加邀请码中转步骤。表单铺满左右，浅色白底配浅灰`#f3f3f3`输入，深色使用全局中性深底 / 深灰输入；文字、按钮、错误色和原生控件均跟随主题。以顶部圆角与黄底分隔，不显示常态边线或勾边投影，保留聚焦轮廓与报错提示。原内边距、字段位置与宽度不变，底部安全区接当前表单底色，禁用 / 等待仍固定`#e5e5e5`。昵称及住址可在个人页后补；密码支持显隐、自动填充及就地校验。可以阅读实际使用约定和隐私说明，成功注册后自动登录并回到原操作。邀请码仅记录来源；旧后端或能力查询失败时，非空邀请码提示暂不可用，清空后仍可注册，不假装保存成功。
- 登录 / 注册品牌区与产品页标题共用 KaiXinTi；`kaixin-display-v2.woff2` 为9,888字节、37个字符，在旧29字基础上补齐“发现、聊天、消息、首页”，保留原字形及版权元数据。字体声明与预加载同用v2文件名，避免复用旧缺字缓存。仅顶部文字等待字体就绪，预留原行高，返回、表单、卷线及操作立即可用；最多等待1500ms，失败或超时后固定系统字体，不因迟到响应再次换字。
- 注册顶部按指定参考采用奶油黄渐变，深色主题使用柔和暖金；顶部文字、返回图标与键盘焦点使用局部深色，保证黄底可读。移除角色身后的装饰底板，原角色与表单位置不变。头图与顶部安全垫层、单个 `theme-color` 共用起色；直接刷新注册深链的首帧也对齐。退出注册恢复当前主题的原配色，多实例和 StrictMode 清理互不影响，不改用户偏好；大屏480px画布外保持全局底色。
- 登录主按钮与注册按钮共用主题主色与胶囊样式；通用弹窗的关闭按钮为透明背景，仅保留主色图标与 44px 点击区，顶部拖拽提示条同样使用主色，浅色近黑、深色近白。抽屉面板与其底部安全区对齐整页柔光画布的底部。通用按钮禁用 / 等待状态的背景固定为 `#e5e5e5`、文字 / 加载图标固定深灰 `#666666`，两种主题一致，不使用透明度混色；消息顶部刷新是局部例外，保持透明仅旋转图标。
- 分类与引导页运行素材为 `gummy-neighbors-personas.webp`：1448×1086、4列×3行、12种小三角 / 细水滴 / 扁团等不同轮廓和眼神，透明 WebP 共499,988字节，保留原外框、缩放和页面位置。`gummy-neighbors-simple.webp`、`gummy-neighbors-cheerful.webp`、`gummy-neighbors-mellow.webp` 仅保留为前期草稿，不是运行素材。元数据见 `src/assets/gummy-neighbors-personas.json`，image_gen 的[最终提示词](../../docs/development/neighbor-help/2026-11-03-gummy-personas-prompt.txt)保留溯源。
- 卡通角色沿透明轮廓增加两层轻白柔光，不是矩形图片边框；仅静态绘制，不改变图集、配色矩阵、占位、点击区或减少动态效果行为。
- `GummyCharacter` 的形象与配色可独立组合：`expression` 接受整数0–11；`color` 接受 `pink`、`yellow`、`lilac`、`blue` 或六位 `#RRGGBB`，例如 `<GummyCharacter expression={6} color="#fcd14a" />`。12种形象 × 4种基础配色提供48种组合，另支持自选颜色。兼容原 `type` 与整数0–2的 `variant` 行选择；有效 `expression` 优先于 `variant`，默认仍按分类稳定展示。换色使用真实 SVG `feColorMatrix`（sRGB），准确映射主体基色并保留白眼、黑线、灰阶与 alpha，不修改原图透明度。
- 本地开发可直接打开 `/dev/characters` 搭配角色；当前调试会话的同 Wi-Fi 手机地址为 [角色组合预览](http://192.168.10.219:5173/dev/characters)，电脑IP变化后以实际局域网地址为准。选择颜色不会重置形象，选择形象保留颜色。该页仅在 `import.meta.env.DEV` 为真时注册，使用真实角色素材，页面自身不请求API、不使用业务模拟数据，也不增加正式导航入口；生产构建不注册或打包该调试页，业务页面使用的角色图集仍正常保留。
- 开发素材预览独立于产品会话布局，即使本地已有登录缓存也不请求恢复账号。进入正常业务页后才挂载原 `AuthProvider`，在业务路由之间切换及页面错误恢复时共用同一份登录状态；原受保护页面的鉴权不变。
- 房号保留在本人资料中，不作为公开作者 / 对话对象资料返回；公开显示昵称、头像及楼栋。新帖默认地点只带楼栋，手动填写的帖子地点会公开展示，已有帖子与草稿的位置文字保持原样。

前端导航约定见 [导航说明](../../docs/interfaces/neighbor-help/frontend-navigation.md)，本次改动和验证见 [开发记录](../../docs/development/neighbor-help/2026-11-03-frontend-ux.md)。
